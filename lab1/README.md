# Лабораторная № 1. Линейная регрессия

Предсказание `RiskScore` по данным заёмщика. [Условие](./docs/cml_lab1.pdf), [решение](./lab1.ipynb).

## Запуск

1. Установить зависимости из корня проекта:

   ```powershell
   & ./.venv/Scripts/python.exe -m pip install -r ./lab1/requirements.txt
   ```

2. Открыть [ноутбук](./lab1.ipynb), выбрать ядро Python из `.venv`.
3. Выполнить все ячейки сверху вниз. Рабочая папка — корень проекта или папка лабораторной.

## Что сделано

Анализ и очистка данных, z-score и min-max, линейная регрессия через аналитическое решение, GD и SGD. Реализованы MSE, MAE, R², MAPE, k-fold и LOO. Дополнительно — L2. Реализации проверяются со sklearn.

После очистки осталось 9332 строки. LOO показан на 200 строках с базовой моделью, 5-fold — на всех очищенных данных.

## Результаты

| Модель | MSE на валидации |
| --- | ---: |
| Базовая | 49,4958 |
| Полиномиальная с L2 | 24,3030 |
| 19 признаков с L2 | 16,6663 |

Итоговый MSE по всем прогнозам 5-fold — **17,9898**. На двух фолдах ошибка выше 18. Признаки выбирались по локальным экспериментам; результат на Kaggle пока неизвестен.

Пороги и формула оценки основаны на [генераторе похожих данных](https://github.com/ENKI0311/Financial-Risk-for-Loan-Approval/blob/main/CSV%20Generation.py). Точное совпадение с нашими данными не установлено. Все обучаемые коэффициенты относятся к линейной регрессии.

Для Kaggle подготовлен [submission.csv](./submission.csv): 5000 строк, колонки `ID,RiskScore`. Файл ещё не отправлен. Повторный запуск обновляет прогнозы.
